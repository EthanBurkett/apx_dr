# Original authoring textures

These full-resolution IWI textures were retained before runtime mip trimming.
Names are SHA-256 hashes. Original names, hashes and dimensions are recorded
in ui/texture_optimization.json.

Git LFS preserves them so fresh checkouts can reproduce model previews.
They are not project sourceRoots and are not shipped in game IWDs.
The model preparation tool checks their hashes before authoring.
