# ApX Deathrun UI

The player glances at progress over a bright, moving game scene. Use a slight
gameplay tint on the Tab scoreboard, with restrained row shading and text shadows.
Other menus can use dark slate panels for longer explanations.

Use the engine's normal/objective fonts and 640x480 virtual coordinates. Keep
scoreboard rows aligned, numbers right aligned and rank/prestige columns distinct.
Use muted blue slate surfaces, pale gray text and restrained warm gold accents.
Show team names and life state as text, rather than relying on red/green alone.
Keep existing keyboard navigation. Explain prestige's exact reset and require a
separate confirmation. Badges use broad metallic silhouettes, exact numbers and
transparent backgrounds; editable SVGs and rendered engine textures share geometry.

Buttons use clipped steel image frames and a warm gold perimeter highlight.
Keep every state's interior clear of lines, chevrons and other label obstacles.
Hover and keyboard focus brighten the frame; activation uses a recessed image.
Unavailable actions use muted frames and cannot take input. Keep labels as live
engine text. The Tab scoreboard has no mouse buttons.

Gameplay HUD elements use compact corner clusters and a three-unit bottom-edge XP line.
Keep the center of play clear. The XP fill is continuous, without segment ticks.
Use a static metallic material only on its narrow fill, with no full-screen shader
effect or looping decorative motion. Keep rank icons at 14 virtual units and
progression text secondary. Show numeric ammo next to the native weapon silhouette.
Health uses a red/gold/mint shader gradient and short damage-only flash/float
feedback. Practice requirements use small unboxed text. Use the transparent ApX
logo in the top left rather than a large text watermark.

Use separate offline and in-server navigation. Loadout is a full-width showcase
with the selected operator, one Primary and a carried knife. Arms follow the
operator by default, with an independent saved arms selection available.
The main menu uses environment artwork rather than an operator preview. Catalog
browsing has fixed result rows, search, an unlocked filter and direct page entry.
Inspecting does not equip. Actual-model turntables use neutral lights, correct
shoulder attachment and optional client-side rotation. Default to the sharper
still view; rotation is an explicit inspection choice.
